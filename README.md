# Propservice Solutions

> **Premier Bengaluru Property Legal, Documentation & Municipal Clearance Platform**

Propservice Solutions is an enterprise-grade web application built for Bengaluru property owners, buyers, and developers to navigate BBMP e-Khata transitions, 30-year Encumbrance Certificate (EC Form 15) verification, Kaveri 2.0 PID mutation, and property title legal scrutiny.

---

## ✨ Features

- **🏛️ BBMP 8-Zone Jurisdiction Directory**: Interactive coverage and liaison tracking across all BBMP zones (East, West, South, Mahadevapura, Bommanahalli, Yelahanka, RR Nagar, Dasarahalli).
- **📋 Legal Service Bento Grid**: Deep-dive breakdowns for BBMP Digital e-Khata, Title Scrutiny, Kaveri 2.0 Mutation, and Arrears Clearance with real-time statutory fee calculation.
- **⚡ Live Bengaluru Municipal Activity Desk**: Real-time filing and endorsement ticker, live municipal event stream, and docket search ledger.
- **🤖 AI Property Document & e-Khata Eligibility Advisor**: Interactive legal eligibility audit and FAQ chat powered by Google Gemini API.
- **💰 Dynamic Fee & Statutory Tax Estimator**: Instant breakdown of government statutory stamp duty, betterment cess, and legal verification charges.
- **✨ Spotlight Cursor Glow & Aurora Mesh**: High-end modern UI styling with Apple/Linear-inspired spotlight card glow effects and ambient GPU-accelerated auroras.
- **❄️ Interactive Festive Theme**: Christmas holiday discount pricing and soft falling snow overlay with user toggle controls.
- **🌓 Bidirectional Scroll Reveal & Dark Mode**: Smooth entrance and exit transitions with system and manual dark mode toggles.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm` or `pnpm`

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/pigeio/Propservice-Solutions-.git
   cd Propservice-Solutions-
   ```

2. Install dependencies:
   ```bash
   npm install --legacy-peer-deps
   ```

3. (Optional) Configure environment variables:
   Copy `.env.example` to `.env` or `.env.local` and configure your API keys:
   ```env
   GEMINI_API_KEY=your_gemini_api_key_here
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.
